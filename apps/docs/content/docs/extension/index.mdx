This guide installs the Crikket extension without the Chrome Web Store.

## Prerequisites

- Chrome or any Chromium-based browser
- `web` and `server` running (local or deployed)
- Dependencies installed in repo root:

```bash
bun install
```

<Steps>
  <Step>

  ### Configure Extension Env

  ```bash
  cp apps/extension/.env.example apps/extension/.env
  ```

  Default values:

  ```bash
  VITE_APP_URL=http://localhost:3001
  VITE_SERVER_URL=http://localhost:3000
  ```

  If your app is deployed, replace those with deployed URLs.

  </Step>

  <Step>

  ### Build Extension Output

  ```bash
  bun run build --filter=extension
  ```

  Output path:

  ```bash
  apps/extension/.output/chrome-mv3
  ```

  </Step>

  <Step>

  ### Load Unpacked in Chrome

  1. Open `chrome://extensions`
  2. Turn on `Developer mode`
  3. Click `Load unpacked`
  4. Select `apps/extension/.output/chrome-mv3`

  </Step>

  <Step>

  ### Verify

  - Extension appears in extensions list
  - Popup opens without errors
  - Recording/capture actions can reach your configured backend

  </Step>
</Steps>

## Update Loop

After extension code changes:

```bash
bun run build --filter=extension
```

Then in `chrome://extensions`, click reload on the Crikket extension.

## Recording from the popup

Video capture uses Chrome `tabCapture` from the extension popup:

- Tab video is recorded together with tab audio and the microphone.
- Tab audio keeps playing in the source tab (it is routed back after capture).
- If you deny microphone permission, recording falls back to tab audio only
  and shows a warning.
- A tab that is not playing audio still records video.

**Switching tabs mid-recording is not supported.** Stay on the tab you started
capturing until you stop.

## Point the extension at another host

The packed extension reads `VITE_APP_URL` and `VITE_SERVER_URL` **at build
time**. Those values are not hardcoded. For Kode GT production both are
`https://crikket.kodegt.com`. For local development they default to
`http://localhost:3001` and `http://localhost:3000`.

Build for a different deployment:

```bash
VITE_APP_URL=https://your-host.example \
VITE_SERVER_URL=https://your-host.example \
  bun run build --filter=extension
```

Then load `apps/extension/.output/chrome-mv3` unpacked, or zip it with:

```bash
bash ./scripts/package-extension.sh
```

On this fork, the `CI` workflow job **Package extension (Load unpacked)**
builds with `VITE_APP_URL` / `VITE_SERVER_URL` set to
`https://crikket.kodegt.com` and uploads `crikket-extension-chrome-mv3`.
Download the zip from the workflow run, unzip it, and load the `chrome-mv3`
folder in `chrome://extensions`.
